# Toast and Snackbar Demo
## Project Overview
A simple Android app developed using Kotlin and XML for the Veda Technology Android Development Track (Day 20). It demonstrates how to display Toast and Snackbar messages for different user actions.
## Technologies Used
- Kotlin
- XML Layouts
- Android Studio
## Features
- Button to trigger a Toast message
- Button to trigger a Snackbar message with an action
## How to Run
1. Clone the repository. 2. Open in Android Studio. 3. Sync Gradle. 4. Run the app.
## Outcome
The application successfully displays temporary feedback messages using Toast and Snackbar.
